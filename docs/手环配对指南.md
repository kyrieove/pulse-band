# 手环配对指南

从零到手环上能看见 Agent 的状态，分两段：**手机和手环上的准备（第 1–3 步）**，然后**在 Pulse 的配置向导里走完 4 步（第 4 步）**。顺利的话 20–30 分钟。

> 全程用到三个软件：手机上的**小米运动健康**和**小米健康研究**，电脑上的 **Pulse**。
>
> 最难的是第 2 步（导出日志）。日志导出来之后，密钥由 Pulse 自动提取，不用手动翻日志、不用复制粘贴。

---

## 第 0 步：装好前置

| 装什么 | 装在哪 | 说明 |
|---|---|---|
| 小米运动健康 | 安卓手机 | 用来绑定手环。已经在用就跳过 |
| 小米健康研究 | 安卓手机 | **只用来导出日志**，导完就可以卸载 |
| Pulse | 带蓝牙的 Windows 电脑 | 从 [Releases](../../../releases/latest) 下载安装 |

---

## 第 1 步：用小米运动健康绑定手环

扫手环上的二维码，正常绑定。已经绑好的直接进下一步。

> 每次重新绑定，手环的密钥都会换一把。所以**先绑定，再导日志**，顺序不能反。

---

## 第 2 步：导出日志

1. 打开手机上的**小米健康研究**。
2. 底部点 **「我的」** → 点 **「关于」**。
3. 在「关于」页面，**快速连续点击小米健康研究的 logo**（像开安卓开发者模式那样连点）。
4. 弹出「log 迁移至 `/storage/emulated/0/Download/ResearchLog`」的提示，点**确定**。

   > 这个连点手势是隐藏开关，不点就不会生成日志。没弹提示就多点几下，或者退出重进再试一次。

5. 用文件管理器找到：

   ```
   手机存储 / Download / ResearchLog / research-<一串数字> / XiaomiFit.main.log
   ```

6. 把这个 `XiaomiFit.main.log` 传到电脑上（数据线、微信文件传输助手、云盘都行）。

   > `research-<数字>` 有好几个文件夹的话，取**最新的那个**（按修改时间排序）。

<details>
<summary><b>如果手机上没有 ResearchLog 目录（备选路径）</b></summary>

用小米运动健康自己导：

1. 小米运动健康 → **意见反馈** → **上传日志**（会在本地留一份导出）
2. 找到导出的 `*log.zip`，传到电脑上
3. 这个 zip **不用解压**，第 4 步直接拖进 Pulse 就行

</details>

---

## 第 3 步：让手环进入可连接状态

**在手环上操作**：设置 → **系统操作** → **连接新手机**

⚠️ **不做这一步，电脑连不上手环。** 手环被手机连着的时候不接受新的连接。

> 这一步**不会**让密钥失效。它和「在小米运动健康里删除设备重新绑定」完全是两回事——后者才会换密钥。

---

## 第 4 步：在 Pulse 里走完配置向导

打开 Pulse →「手环」页 → 点 **「配置手环」**，向导一共 4 步。每步做完点「下一步」，最后一步点「完成向导」。

### 4.1 导入手机日志

1. 把第 2 步的 `XiaomiFit.main.log`（或那个 `.zip`、或整个 `research-数字` 文件夹）**拖进去**，也可以点「浏览本地文件…」。
2. 在设备列表里确认选中的是你的小米手环（Pulse 会自动选中列表里的第一块小米手环）。
3. 点 **「保存并继续」**，保存成功后会自动进入下一步。

Pulse 会自动从日志里提取 32 位密钥，并和选中手环的蓝牙地址一起保存在本机。解析全程在本机进行，不上传任何东西。

> 本机已经配置过手环的话，向导会提示「检测到本机已有手环配置」，可以直接复用，也可以重新导入日志覆盖（比如重新绑定过手环之后）。

### 4.2 连接手环

确认手环还在「连接新手机」状态、屏幕亮着、离电脑不远，点 **「发起连接」**。

**第一次连接**要确认两次：

1. 手环屏幕上弹出配对请求，**在手环上点接受**
2. 电脑右下角随后弹出 Windows 蓝牙配对窗口，**在电脑上点允许**

看到「已连接 (协议就绪)」就过关了。

配对成功后，**以后每次连接只需要在手环上点接受**，电脑上不会再弹窗。

失败时看 [故障排查](故障排查.md) 第二节。

### 4.3 安装手环应用

在「安装 Pulse 快应用」卡片里点 **「一键安装到手表」**，把随安装包内置的手环应用推到手环上。完成后手环上会多出一个叫 **Pulse** 的应用。

> ⚠️ 这个 `.rpk` 只在作者本人的手环上验证过。如果安装失败或装上打不开，请附上「运行诊断」生成的脱敏报告。

### 4.4 验证额度

在手环上打开 **Pulse** 应用，对照电脑上显示的额度，确认手环上能看到数据后点 **「我已在手环上确认显示正常」**。

---

## 第 5 步：接上 Claude Code

1. Pulse →「设置」→「检测 Agent 接入」→ Claude Code 一行点 **「修复」**
2. 看到「已安装 · 请重开 Claude Code 会话后生效」后，重开一个 Claude Code 会话

这一步会往 `~/.claude/settings.json` 里加 5 个 hook（会话开始 / 提交提示 / 工具调用前后 / 结束），并**自动备份原文件**到 `settings.json.pulse-backup`。你已有的其他 hook 一个都不会动。

转发脚本用 Pulse 自带的运行时执行，**不需要你安装 Node.js**。

> Codex 和 Antigravity 不需要安装任何东西，Pulse 会自动识别。

---

## 完成

现在在电脑上让 Agent 干活，抬手看手环——正在跑的工具名和计时器应该实时在动。

打开手环上的 **Pulse** 应用，左右滑可以切换会话状态和额度页面。

电脑上还有一个桌面悬浮窗，各 Agent 的额度一屏看完：

## 日常使用

- **连手环**：手环上选「连接新手机」→ Pulse「手环」页点「连接手环」→ 在手环上点接受。
- **回到手机**：Pulse 里点「断开连接」或从托盘退出 Pulse，然后在小米运动健康里重新连接手环。
- **换表盘**：连上手环后打开「表盘」页，可以切换已安装的表盘，或拖入本地 `.bin` 表盘文件安装。
- **推其他快应用**：「手环」页 →「推送其他快应用 (.rpk)」。

---

## 附：手环是怎么联网的

小米手环 10 自己不能联网，它通过蓝牙向电脑请求数据。Pulse 内置的 `pulse-core` 负责蓝牙连接和协议处理，收到手环的请求后，从 Pulse 的本机状态服务取出 Agent 状态和额度再发回手环。手环和电脑之间的数据只走本机蓝牙，不经过任何第三方中转。
