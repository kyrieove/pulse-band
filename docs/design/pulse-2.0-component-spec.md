# Pulse 2.0 组件设计规范 (Component Specifications)

本文档详细定义 Pulse 2.0 包含的 17 项核心 UI 组件的尺寸、间距、排版、状态流转、微交互以及在 Light 与 Dark 主题下的具体实现表现。

---

## 1. 核心状态机模型 (Core State Machines)

### 1.1 手环连接状态规范 (Connection State Machine)

手环连接卡片及指示器必须严格按以下 7 态状态机渲染，严禁任何假成功状态，用户文案统一使用“认证信息”或“设备凭据”：

| 状态 Key | 状态中文名 | 状态指示 Icon | 语义色彩 | Spinner | 主按钮文案与动作 | 状态说明文案 |
|---|---|---|---|---|---|---|
| `idle` | 未连接 | `BluetoothOff` | `--status-idle` | 否 | “连接手环” (Primary) | “手环处于未连接状态，点击开始建立连接” |
| `starting` | 启动服务中 | `Loader2` | `--status-working` | 是 (匀速旋转) | “取消” (Secondary) | “正在启动设备服务…” |
| `searching` | 查找手环中 | `Radio` | `--status-working` | 是 (脉冲呼吸) | “取消” (Secondary) | “正在查找已配置的小米手环 10…” |
| `connecting` | 建立连接中 | `RefreshCw` | `--status-working` | 是 (匀速旋转) | “取消” (Secondary) | “正在连接手环…” |
| `authenticating` | 验证身份中 | `KeyRound` | `--status-working` | 是 (缓动旋转) | “取消” (Secondary) | “正在校验设备凭据与认证信息…” |
| `connected` | 已连接 | `CheckCircle2` | `--status-success` | 否 | “断开连接” (Secondary) | “已连接 · 数据已同步” (或“数据尚未同步到手环”) |
| `error` | 连接异常 | `AlertCircle` | `--status-error` | 否 | “重新连接” (Primary) | 动态提示：“认证信息不匹配” 或 “手环正被占用，请在手环选择连接新手机” |

---

## 2. 核心组件逐项规范 (17 项)

### 2.1 Sidebar (侧边导航栏)
- **用途**：应用全局主导航（严格限制仅有三个一级导航：概览、手环、设置）与底部悬浮窗快捷开关。
- **视觉层级**：基础结构层，垂直铺满视窗左侧。
- **尺寸**：固定宽度 `200px`，高度 `100%`。
- **品牌区域**：顶部常驻展示 **Pulse 2.0** 品牌标识及版本徽标。
- **Spacing**：外边距 `p-3 (12px)`，导航项之间 `gap-1.5 (6px)`。
- **Typography**：
  - 品牌主标题：“Pulse 2.0” `text-sm (14px)`，Bold。
  - 导航项目：`text-sm (13px)`，Medium。
- **状态行为**：
  - Default: 文字 `--text-secondary`，无背景。
  - Hover: 背景 `--bg-app`，文字 `--text-primary`，过渡 `150ms`。
  - Active (选中态): 背景 `--bg-elevated`，文字 `--accent-primary`，边框 `1px solid var(--border-strong)`，阴影 `--shadow-sm`，右侧带活跃高光圆点。
  - Focus: 键盘可聚焦，高亮 focus ring。
- **Light / Dark 差异**：
  - Light: 背景 `#FFFFFF`，右边框 `1px solid rgba(15, 23, 42, 0.08)`。
  - Dark: 背景 `#10131B`，右边框 `1px solid rgba(248, 250, 252, 0.08)`。

---

### 2.2 TopBar / TitleBar (自绘标题栏)
- **用途**：Windows 无边框窗口控制、窗体拖拽区（`-webkit-app-region: drag`）、主副标题呈现、窗口三联控制按钮。
- **主标题规范**：**用户可见主标题必须固定为“Pulse 2.0”**，严禁使用单独的“Pulse”。
- **视觉层级**：顶部吸顶，高度 `40px`。
- **尺寸**：宽度 `100%`，高度 `40px`，内边距 `px-4 (16px)`。
- **Spacing**：图标与主标题间距 `8px`，主副标题间距 `6px`。
- **Typography**：
  - 应用主名：“Pulse 2.0” `text-sm (13px)`，Semibold，`--text-primary`。
  - 当前副标题：`text-xs (11px)`，Regular，`--text-muted`（如“· 概览”、“· 手环”、“· 设置”）。
- **Light / Dark 差异**：
  - Light: 底色 `#FFFFFF`，底部边框 `1px solid rgba(15, 23, 42, 0.06)`。
  - Dark: 底色 `#10131B`，底部边框 `1px solid rgba(248, 250, 252, 0.06)`。

---

### 2.3 BandConnectionCard (手环连接核心卡片)
- **用途**：概览页第一视觉中心，统领手环连接生命周期与主操作。
- **信息保护与数据呈现硬性规范**：
  - **展示内容仅限**：
    1. 设备型号名：“Xiaomi Smart Band 10”；
    2. 设备标识：“已配置手环”；
    3. 当前连接状态（如“已连接”、“未连接”）；
    4. 连接 / 断开主操作按钮；
    5. 连接阶段指示；
    6. 最后同步状态（如“最后同步：刚刚”或“尚未同步到手环”）。
  - **绝对禁止展示**：禁止展示完整 MAC 地址，禁止设计“查看完整地址”开关，禁止展示凭据与密钥明文。
- **视觉层级**：一级主卡片，最高视觉显著度。
- **尺寸**：宽度 `100%`，内边距 `p-5 (20px)`，圆角 `--radius-lg (14px)`。
- **状态表现**：
  - Idle: 柔和冷灰边框，中性徽章，Primary 按钮“连接手环”。
  - Connecting: 柔和海蓝边框，内嵌 `ConnectionProgress`，按钮置为“取消”。
  - Connected: 柔和翠绿边框，StatusBadge 显“已连接”，展示最后同步状态与“断开连接”按钮。
  - Error: 柔和赤红警示边框，展示脱敏错误排查建议与“重新连接”按钮。

---

### 2.4 ConnectionProgress (连接阶段分步反馈指示条)
- **用途**：在连接发起时直观展示握手阶段。
- **视觉层级**：嵌于 `BandConnectionCard` 内部的二级动效组件。
- **尺寸**：高度 `28px`，宽度 `100%`，圆角 `--radius-full`。
- **四步阶段规范**：
  1. `启动服务` ➔ 2. `查找手环` ➔ 3. `建立连接` ➔ 4. `验证凭据`
- **节点表现**：
  - 未到达：灰色虚线环；
  - 当前进行中：高亮蓝色脉冲并带微型 Spinner；
  - 已完成：翠绿色小勾。

---

### 2.5 AgentCard (AI Agent 监控卡片 - 默认态)
- **用途**：概览页第二核心视觉区，展示已检测到或已启用的 Agent（Claude Code、Codex CLI、Antigravity 等）。
- **数据驱动规范 (Data-Driven)**：
  - 默认只保证展示 5 项核心指标：
    1. **Agent 名称**
    2. **主要额度**（按该 Agent 实际提供的指标动态渲染，如百分比或调用次数）
    3. **重置时间**（若该 Agent 提供）
    4. **当前状态**（待命 / 思考中 / 运行工具中）
    5. **运行计时**（仅在执行任务时动态计时，格式如 `01:24s`）
  - 不做统一固化的 5 小时假定；不存在的数据字段不渲染。
- **视觉层级**：核心数据卡片。
- **尺寸**：宽度 `100%`，内边距 `p-4 (16px)`，圆角 `--radius-md (10px)`。
- **状态设计**：
  1. **Idle**：中性状态点，展示主要额度与重置时间。
  2. **Running**：科技蓝呼吸灯，显示当前工具名称与计时秒表。
  3. **Quota Warning**：额度进度条变更为琥珀色警告色。
  4. **Quota Critical**：额度进度条变更为赤红色警示色。
  5. **Expanded**：过渡至展开态。

---

### 2.6 AgentCardExpanded (AI Agent 监控卡片 - 展开态)
- **用途**：点击卡片后展开，展示该 Agent 真实具备的深度指标。
- **数据驱动规范**：
  - **只展示该 Agent 真实提供的其他额度周期**（如日配额、周配额、Token 消耗等）；
  - **数据更新时间**；
  - **真实可获得的详细状态**；
  - 任何不存在的指标项坚决不显示，不占位。
- **尺寸与排版**：平滑伸展（`max-h-[240px]`），内嵌微网格自适应排列。

---

### 2.7 StatusBadge (语义状态徽章)
- **用途**：用于设备状态、Agent 状态的紧凑文字标签。
- **尺寸**：高度 `22px`，内边距 `px-2.5 py-0.5`，圆角 `--radius-full`。
- **色彩规范**：
  - Success: 背景 `rgba(22, 163, 74, 0.1)`，文字 `#16A34A` (Light) / `#22C55E` (Dark)。
  - Working: 背景 `rgba(2, 132, 199, 0.1)`，文字 `#0284C7` (Light) / `#38BDF8` (Dark)。
  - Warning: 背景 `rgba(217, 119, 6, 0.1)`，文字 `#D97706` (Light) / `#F59E0B` (Dark)。
  - Error: 背景 `rgba(220, 38, 38, 0.1)`，文字 `#DC2626` (Light) / `#EF4444` (Dark)。
  - Idle: 背景 `rgba(100, 116, 139, 0.1)`，文字 `#64748B` (Light) / `#94A3B8` (Dark)。

---

### 2.8 QuotaIndicator (自适应配额进度条)
- **用途**：数据驱动的额度可视化。
- **尺寸**：高度 `6px`，宽度 `100%`，圆角 `--radius-full`。
- **表现**：根据当前 Agent 的百分比自适应填充 `--quota-normal`、`--quota-warning` 或 `--quota-critical`。

---

### 2.9 PrimaryButton (主要操作按钮)
- **用途**：“连接手环”、“重新连接”等主要指引操作。
- **尺寸**：高度 `36px`，内边距 `px-4 (16px)`，圆角 `--radius-md (10px)`。
- **状态行为**：
  - Default: 背景 `--accent-primary`，文字纯白；
  - Hover: 背景 `--accent-hover`；
  - Active: 缩放微反馈 `scale(0.98)`；
  - Disabled: 不透明度 `40%`，禁用光标；
  - Loading: 内嵌 `Loader2` 旋转。

---

### 2.10 SecondaryButton (次要操作按钮)
- **用途**：“断开连接”、“取消”、“刷新”等次级操作。
- **尺寸**：高度 `36px`，内边距 `px-3.5 (14px)`，圆角 `--radius-md (10px)`。
- **表现**：透明底衬，`1px solid var(--border-strong)` 边框，Hover 时背景轻微着色。

---

### 2.11 SettingsGroup (设置项分组卡片)
- **用途**：设置页中的配置组容器（外观、Agent、手环同步、高级维护）。
- **尺寸**：宽度 `100%`，圆角 `--radius-lg (14px)`，内边距 `p-4 (16px)`。
- **分组与视觉权重控制**：
  - 外观、Agent、手环同步为常规强调度；
  - **高级维护卡片置于底部，边框与文字采用低权重弱化处理**。

---

### 2.12 Toggle (平滑二元开关)
- **用途**：二元状态切换（如桌面悬浮窗开启、各 Agent 独立监控显示）。
- **尺寸**：槽底 `36px × 20px`，圆核 `16px × 16px`。

---

### 2.13 EmptyState (优雅空状态)
- **用途**：未检测到已启用 Agent 时的指引界面。
- **表现**：居中对齐，展示矢量图标、清晰引导文本及快捷操作（如“前往 Agent 设置”）。

---

### 2.14 ErrorState (脱敏错误处理容器)
- **用途**：蓝牙连接失败、凭据失效时的现场错误指引。
- **数据安全要求**：严禁出现未脱敏的原始崩溃堆栈或密钥字节，统一展示指引性文案（如“设备凭据已失效，请重新配置”）。

---

### 2.15 CollapsibleAdvancedSection (可折叠高级工具区)
- **用途**：手环页收纳高级开发功能。
- **硬性规格约束**：
  - **首版仅收纳规格已确认的唯一功能：“推送其他快应用”**；
  - **默认状态：必须强制折叠**，禁止展开喧宾夺主；
  - 严禁在此区域添加任何未确认的底层日志、蓝牙抓包或协议重置功能。

---

### 2.16 MiniBar (桌面迷你悬浮小岛)
- **用途**：置顶于 Windows 桌面的非侵入式极简悬浮胶囊。
- **尺寸**：`320px × 36px`，极致圆角 `--radius-full`。
- **内容限制**：仅展示已启用 Agent 的精简额度、当前运行状态与运行计时。
- **交互规范**：点击立即呼出 Pulse 2.0 窗口并定位至“概览”页。
- **双模态磨砂玻璃**：
  - Light: 高透白磨砂玻璃 `rgba(255, 255, 255, 0.88)`，`backdrop-filter: blur(20px)`；
  - Dark: 暗石板磨砂玻璃 `rgba(20, 24, 36, 0.82)`，`backdrop-filter: blur(24px)`。

---

### 2.17 MiniBarAgentItem (MiniBar 单体项)
- **用途**：MiniBar 内部单个 Agent 的微缩胶囊单元。
- **尺寸**：宽度自适应，高度 `24px`。
- **内容**：极简简称（如 `Cl`、`Cx`、`Ag`）、呼吸状态灯、精简额度数值与执行计时秒表。
