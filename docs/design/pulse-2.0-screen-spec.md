# Pulse 2.0 页面布局规范 (Screen & Layout Specifications)

本文档定义 Pulse 2.0 三大核心主屏（概览、手环、设置）以及桌面悬浮小岛 (MiniBar) 的完整页面级布局、栅格结构、信息层级与状态展示规范。

---

## 1. 全局窗体与布局栅格 (Window & Layout Grid)

### 1.1 窗口与工作区参数
- **窗口物理尺寸**：标准设计尺寸为 `920px × 640px`（最小允许尺寸 `840px × 580px`）。
- **水平分割**：
  - 左侧边栏 (Sidebar)：固定 `200px` 宽，不可折叠隐藏。
  - 右侧主工作区：`flex-1`，自适应拉伸。
- **垂直分割**：
  - 顶部自绘标题栏 (TopBar)：固定 `40px` 高。
  - 内容可视区域：`600px` 高，超出自动产生平滑细滚动条。
- **工作区内边距与间距节奏**：
  - 内边距：`p-6 (24px)`。
  - 主块垂直间距：`space-y-5 (20px)`。
  - 卡片内部组件间距：`gap-3 (12px)` 或 `gap-4 (16px)`。

## 2. 概览页规范 (Screen 1: Overview)

### 2.1 核心信息流与视觉层级（硬性先后顺序）
概览页是用户高频查看的核心看板，**信息流必须严格遵守以下自上而下的物理顺序**：

```text
┌──────────────────────────────────────────────────────────┐
│ 1. 手环连接状态与主控卡片 (BandConnectionCard)           │
│    - 设备名称、连接状态徽章 (StatusBadge)、MAC           │
│    - 连接 / 断开主操作按钮 (PrimaryButton / Secondary)  │
│    - 连接阶段多步指示条 (ConnectionProgress: 握手反馈)   │
├──────────────────────────────────────────────────────────┤
│ 2. AI Agent 活跃状态与额度区 (Agent Quota Section)       │
│    - 卡片列表：仅展示已检测或启用的 Agent                │
│    - 默认态：Agent 名称、主要剩余额度条、重置时间、状态  │
│    - 运行中态：高亮呼吸灯、当前调用工具、运行耗时秒表    │
│    - 展开态：周期用量、更新时间、深度调试状态            │
└──────────────────────────────────────────────────────────┘
```

### 2.2 详细区域布局说明

#### 区域 1：手环连接主卡片
- **位置**：页面顶部，单列通栏。
- **结构划分**：
  - **头部行 (Flex Between)**：
    - 左侧：手环矢量图标 + “Xiaomi Smart Band 10”标题 + `MAC: **:**:**:5A:F2`（点击可脱敏切换）+ 协议类型徽章。
    - 右侧：手环连接状态徽章（如“已连接”、“正在握手…”、“未连接”）。
  - **主操作与反馈区**：
    - 当处于 `idle` 态：显示居右的 `PrimaryButton`（“连接手环”），伴随辅助说明“保持手环在电脑蓝牙范围内”。
    - 当处于 `starting` / `searching` / `connecting` / `authenticating` 过程态：
      - 主按钮切换为 `SecondaryButton`（“取消”）；
      - 并在卡片中央展开 `ConnectionProgress` 进度轴，直观显示当前命中的具体阶段（启动服务 ➔ 查找广播 ➔ RFCOMM 连接 ➔ 密钥认证）；
    - 当处于 `connected` 态：显示“断开连接”按钮，并展示“最近同步于 1 秒前”。
    - 当处于 `error` 态：卡片底部弹出嵌入式 `ErrorState`，提示具体排查建议（如“请在手环设置中开启连接新手机”），右侧提供“重试连接”按钮。

#### 区域 2：Agent 监控与额度区
- **位置**：紧跟手环卡片下方。
- **头部标题**：
  - 左侧：“已激活的 AI Agent” (`text-sm font-semibold text-primary`)；
  - 右侧：“自动刷新 · 5 小时窗口” (`text-xs text-muted`)。
- **卡片网格**：
  - 采用单列堆叠卡片布局（`space-y-3`），每张卡片代表一个已支持并检测到的 Agent（Claude Code、Codex CLI、Antigravity）。
  - **空状态 (Empty State)**：若本机未检测到任何 Agent 运行环境，则呈现 `EmptyState`：“尚未检测到运行中的 AI Agent”，并提供“一键安装 Claude Hook”快捷按钮。

## 3. 手环管理页规范 (Screen 2: Band Management)

### 3.1 页面目标与功能边界
- 聚焦设备管理、固件与快应用状态维护。
- **边界约束**：
  - 严禁放置任何不可用的“表盘市场”、“表盘设计器”等虚假入口；
  - “推送其他快应用”作为高级开发工具存在，**必须收纳进默认折叠的高级区域**，不得成为页面视觉焦点。

### 3.2 布局结构 (自上而下)

1. **设备硬件概览卡 (Device Profile Card)**：
   - 大图标 + 设备官方型号名（Xiaomi Smart Band 10）；
   - 蓝牙物理硬件状态、信道质量、固件版本号；
   - 快速操作栏：“断开连接”、“更换手环 / 重新配对”。

2. **Pulse 手环快应用卡片 (Band App Runtime Card)**：
   - 呈现安装在手环端的配套快应用版本（如 `Pulse Band App v1.1.0`）；
   - 若发现新版本，高亮显示“有可用更新”徽章并提供“推送更新至手环”按钮；
   - 若手环端未安装快应用，显示显著引导卡片与“一键推送安装”按钮。

3. **高级工具区域 (CollapsibleAdvancedSection)**：
   - **默认状态：强制折叠**；
   - 点击折叠栏右侧箭发展开；
   - 展开后提供：
     - 手动推送本地 `.rpk` 扩展应用投放区（拖拽上传文件）；
     - 蓝牙底层包日志监控入口；
     - 极简协议重置。

## 4. 设置页规范 (Screen 3: Settings)

### 4.1 设置项的四组架构与权重控制
设置页严格分为四个 `SettingsGroup` 卡片，自上而下排列，**高级维护的视觉权重必须降到最低**：

```text
┌──────────────────────────────────────────────────────────┐
│ 1. 外观设置 (Appearance)                                  │
│    - 主题模式：亮色 (Light - 默认) / 深色 (Dark) / 跟随系统 │
│    - 桌面悬浮窗 (MiniBar)：显式开启/关闭 Toggle 开关      │
│    - 悬浮窗吸附偏好                                      │
├──────────────────────────────────────────────────────────┤
│ 2. Agent 监控设置 (Agent Integration)                    │
│    - Claude Code 状态监测与 Hook 安装状态                │
│    - Codex CLI / Antigravity 独立监控开关                │
├──────────────────────────────────────────────────────────┤
│ 3. 手环同步设置 (Band Synchronization)                   │
│    - 同步刷新间隔选择 (3s / 5s / 10s)                    │
│    - 熄屏时是否暂停蓝牙广播                              │
│    - 更换手环 / 重新提取 AuthKey 引导流程入口             │
├──────────────────────────────────────────────────────────┤
│ 4. 高级维护 (Maintenance & Diagnostics)                  │
│    [视觉权重最低：背景更淡、边框更细、文字缩小至 text-xs]   │
│    - 运行诊断中心入口 (打开独立诊断浮层/面板)             │
│    - 脱敏运行日志查看与一键复制                          │
│    - 生成 GitHub Issue 专用排查诊断报告                  │
│    - 检查应用版本与 GitHub Release 更新                  │
└──────────────────────────────────────────────────────────┘
```

## 5. 桌面悬浮小岛规范 (MiniBar Specification)

### 5.1 尺寸、位置与多 Agent 呈现
- **默认形态**：胶囊药丸形 (`320px × 36px`，`rounded-full`)。
- **堆叠与多 Agent 规则**：
  - 空间最多支持并行展示 `2` 个活跃 Agent 标签。
  - 若同时检测到超过 2 个 Agent 在运行，优先展示“正在执行工具”的 Agent，次优展示“思考中”，其余折叠为 `+1` 徽标。
- **点击交互行为**：
  - 单击或双击悬浮胶囊：立即呼出 Pulse 2.0 主视窗，并直接激活定位至“概览”页。
- **主题联动**：
  - 主应用切换为 Light 时，MiniBar 同步切换为白色磨砂玻璃；主应用为 Dark 时，同步切换为深石板灰磨砂玻璃。
