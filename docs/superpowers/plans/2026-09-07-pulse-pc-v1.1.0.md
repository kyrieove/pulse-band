# Pulse PC v1.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pulse PC v1.1.0 as a three-page daily-use app with explicit manual band connection, copyable diagnostics, truthful versioning, clean shutdown, and a transparent MiniBar.

**Architecture:** Keep the existing Electron main/preload/React renderer split. Make OronBox lazy by preventing all startup RPC calls and centralizing daemon preparation in `OronBoxBridge.ensureReady()`, invoked only by explicit band operations. Move existing UI blocks instead of rebuilding their business logic, and extract only pure formatting/policy functions that need regression tests.

**Tech Stack:** Electron 44, React 19, TypeScript 7, Vite 8, Tailwind CSS 4, Node test runner, electron-builder/NSIS, GitHub Actions.

- [ ] **Step 4: Add lazy bridge preparation**

Implement one idempotent `ensureReady()` path in `OronBoxBridge`:

```ts
private ready: Promise<void> | null = null;

private ensureReady(): Promise<void> {
  if (!this.ready) {
    this.ready = (async () => {
      await this.client.start();
      await this.client.call('settings.set', { key: 'auto_reconnect', value: false });
      await this.applyBootMode();
      this.startPolling();
      await this.refreshAll();
    })().catch((error) => {
      this.ready = null;
      throw error;
    });
  }
  return this.ready;
}
```

Call it from explicit connect, RPK installation, compatibility-mode changes and time sync. Do not call it from `attach()`, startup, ordinary diagnostics, or timers.

- [ ] **Step 6: Make manual connect and time sync explicit**
