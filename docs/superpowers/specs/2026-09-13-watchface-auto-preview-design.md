# 表盘自动预览设计

日期：2026-09-13

## 目标与边界

Pulse 在后台自动把电脑能访问到的现代小米表盘 `.bin` 内嵌预览解码为 PNG。解码只在首次见到文件或文件内容变化时执行；进入表盘页面只读取缓存，不临时解析大文件。

第一版处理两类输入：

1. 仓库 `watch-face` 目录中的现有 `.bin`，作为首次启动的种子数据。
2. 用户以后通过 Pulse 安装的 `.bin`。

手环已经安装、但电脑没有对应 `.bin` 的表盘无法生成真实预览，继续显示诚实的占位状态。第一版不扫描手机、不联网下载，也不尝试从手环文件系统读取表盘包。

## 技术选择

采用 `band10-toolkit` 的 MIT 许可格式研究与解码思路并保留必要归属说明，在 Pulse 主进程实现所需的最小子集：

- 校验 `5A A5 34 12` 文件头。
- 读取主头 `0x20` 处的 `previewOffset`。
- 解码已验证的 BGRA、调色板和 RLE v1/v2 图像块。
- 将像素编码为 PNG，复用现有 `WatchfacePreviewStore` 保存。

不引入 AIoT、EasyFace、Mi Create 或闭源编译器运行时，也不接入完整的表盘编辑器/渲染器。

## 后台流程

### 应用启动

主进程在应用就绪时启动一个非阻塞预览准备任务：

1. 扫描存在时的 `watch-face` 目录，只读取 `.bin` 普通文件。
2. 从每个包读取表盘 ID、名称、预览偏移和内容哈希，不因此启动蓝牙或读取手环列表。
3. 只有包内 ID 合法时才写入对应缓存；全零或无效 ID 不按名称猜测，等该文件以后经 Pulse 安装并取得设备最终 ID 后再处理。
4. 对已有同哈希自动缓存直接跳过；手动缓存也直接跳过。
5. 只解码缺失或内容已变化的自动缓存。

任务失败只记录单个文件的安全错误，不阻塞窗口启动、手环连接或其他表盘处理。预览服务保留这次准备任务的 Promise；表盘页调用 `preview.list()` 时会等待它结束，因此快速打开页面也不会与首次生成发生竞态。

### 安装表盘

用户通过 Pulse 安装 `.bin` 时，安装流程已经拥有文件路径和设备最终返回的表盘 ID：

1. 设备确认安装成功或已存在后，将文件路径、最终 ID 和安装阶段已计算的哈希交给预览服务。
2. 预览服务检查缓存；预览失败被捕获并记录，不能把设备安装成功改成失败。
3. 缓存缺失或自动缓存哈希变化时解码并写入 PNG。
4. 安装调用在这次短暂的本地准备结束后返回；渲染层重新读取预览映射，再刷新表盘列表。

预览失败不改变已经成功的设备安装结果。

## 缓存规则

沿用 `<userData>/watchface-previews/`：

- 索引键仍为设备表盘 ID。
- 自动条目增加源文件内容哈希，用于判断是否需要重建。
- `source: manual` 永远优先，自动任务不得覆盖用户手动关联的图片。
- `source: auto` 且哈希相同：不解码图像、不重新编码。
- `source: auto` 且哈希不同：原子替换同一 PNG 和索引条目。
- 缓存损坏或 PNG 丢失：下次后台准备时自动补建。

不长期复制或保留原始 `.bin`，只保存生成的 PNG 和最小索引信息。

## 页面行为

表盘页继续通过现有 `preview.list()` 一次性读取缓存。首次读取若撞上启动准备任务，由主进程服务内部等待任务完成；页面无需维护解码进度或新增推送协议。安装成功后再读取一次预览映射。

卡片状态按优先级显示：手动预览、自动预览、设备背景色、无图占位。自动预览不得伪装成实时屏幕截图；它是表盘包内置的静态预览。

## 错误处理

- 非目标文件头、越界偏移、未知图像编码、RLE 损坏：跳过该文件并记录原因。
- 单个表盘失败不终止批处理。
- 不把默认图或空画布写入成功缓存。
- 大小、宽高和解压后像素数设上限，避免异常包造成过量内存使用。
- 不在用户界面展示底层文件路径或二进制解析细节。

## 验证

### 自动化

- 使用三个现有真实 `.bin` 验证输出尺寸和 PNG 可解码性。
- 测试 BGRA、调色板、RLE v1/v2、错误文件头、越界和截断输入。
- 测试相同哈希跳过、不同哈希重建、手动缓存不覆盖。
- 测试安装成功后触发，安装失败不写入，以及解码失败不改变安装结果。

### 应用验证

- 清理残留 Electron 与 `pulse-core` 后运行当前构建。
- 首次启动确认后台生成缓存，表盘页能显示对应真实预览。
- 第二次启动确认缓存文件时间不变，证明没有重复解码。
- 安装一份新 `.bin`，确认安装完成后预览自动出现。
