# MiniBar 圆环会话状态动效原型规格

## 目标

制作一个 HyperFrames 短动效原型，并排比较三种仅依靠现有额度圆环表达任务状态的方案。原型不修改 Pulse 产品代码。

## 固定约束

- 保留当前 40×40 SVG 圆环、Agent Logo、品牌色与下方额度百分比。
- 不增加状态点、文字标签、提示条或第二层圆环。
- 百分比保持静止；只有现有额度环的描边参与状态动画。
- 三版使用同一状态序列：静止 1 秒 → 开始 → 工作中 → 完成 → 回到原额度。
- 完成后圆环必须恢复到演示开始时的额度值，不能让状态动画看起来像额度变化。

## 三种方案

### A · 游光

开始时一道高亮沿额度弧运行一圈；工作中仅弧线端点保持缓慢流动；完成时整环短暂闭合，再回落到原额度。

### B · 呼吸

开始时额度环由细变粗并提亮；工作中整条额度弧低频呼吸；完成时做一次克制的收缩回弹，再恢复静态。

### C · 扫描

开始时额度弧被顺时针扫描唤醒；工作中描边呈轻微虚实扫动；完成时反向擦除扫描效果，保留并恢复原额度弧。

## 交付与验收

- 交付一个 HyperFrames 项目，三版在同一画面并排同步播放，便于直接比较。
- HyperFrames `check` 必须通过，并生成覆盖静止、工作中、完成三个关键时刻的快照。
- 检查通过后先提供浏览器预览；只有用户明确选择渲染时才导出视频。
