# 故障排查

这一页记的是试错换来的结论。**卡住了先看这里，别自己重新摸索。**

遇到任何问题，第一步都是：Pulse →「运行诊断」→ **「一键完整诊断」**。它只读取当前状态，不会修改蓝牙、设备或任何配置。

---

## 一、先分清「连接新手机」和「解绑」

这两个词长得像，成本差一个数量级。搞混会白白多跑一遍导日志流程。

| 动作 | 怎么做 | 密钥换不换 | 成本 |
|---|---|---|---|
| **A. 进「连接新手机」模式** | 手环上：设置 → 系统操作 → 连接新手机 | ❌ **不换** | 手环上点一下；切回手机时要在小米运动健康里重新连接 |
| **B. 真·解绑重绑** | 小米运动健康里删除设备 → 重新扫码绑定 | ✅ **每次都换** | 要重新导出日志，在配置向导里重新导入 |

[配对指南](手环配对指南.md)第 3 步说的是 **A**，不是 B。

手环在「手机」和「电脑」之间来回切换，成本就是在手环上点一下，**不需要重新绑定，也不需要换密钥**。

## 二、连接失败

连接失败时，「手环」页会显示失败卡在哪一步（启动服务 / 查找手环 / 建立连接 / 验证身份），并给出一句提示。按提示对照下表：

| Pulse 提示 | 说明 | 怎么修 |
|---|---|---|
| 手环蓝牙通道已被占用，请在手环上选择「连接新手机」进入可连接模式 | 蓝牙层没连上，**最常见的原因是手环还被手机连着** | 手环上：设置 → 系统操作 → 连接新手机；仍不行就把手机蓝牙关掉再试 |
| 连接超时，请确认手环位于电脑蓝牙通信范围内并保持亮屏 | 手环没响应 | 手环放到电脑旁边，点亮屏幕后重试；留意手环屏幕上的配对请求要点接受；第一次连接时电脑上还会弹出 Windows 蓝牙配对窗口，也要点允许 |
| 未找到目标手环，请确保手环蓝牙已开启 | 电脑找不到配置里的那块手环 | 确认电脑蓝牙已打开；换过手环的话要重新走配置向导 |
| 设备认证信息失效或不匹配 | **蓝牙通道是通的，问题收敛到密钥** | 见下方「密钥不对」 |

### 密钥不对

看到认证失败其实是好消息：蓝牙、通道、协议都没问题，只剩密钥。

1. **你导日志之后重新绑定过手环吗？** 重新绑定会换密钥。重新导出一次日志，在「手环」页 →「配置手环」里选「重新导入新日志覆盖」。
2. **日志是不是旧的？** `ResearchLog` 下有多个 `research-<数字>` 文件夹时，取最新的那个。
3. 两种日志导出方式都试一下：小米健康研究的 `XiaomiFit.main.log`，或小米运动健康「上传日志」得到的 zip。

> 在手环上重新「连接新手机」**不会**修好密钥问题，在 Windows 蓝牙设置里删掉手环重新配对也不会。

## 三、运行诊断各项怎么看

「一键完整诊断」会逐项给出 通过 / 警告 / 失败：

| 检查项 | 警告或失败时 | 怎么修 |
|---|---|---|
| Pulse 状态服务 / Hook 接收服务 | 本机服务没起来，端口 `8765`（状态服务）或 `41789`（Hook 服务）可能被占用 | 从托盘退出 Pulse 重开；仍失败就重启电脑 |
| Claude Code Hook | Hook 未安装或转发脚本缺失 | 「设置」→「检测 Agent 接入」→ Claude Code 一行点「修复」 |
| 设备守护进程 | `pulse-core` 尚未启动 | 正常：它只在点「连接手环」时启动。连接后仍是警告就退出 Pulse 重开 |
| 手环连接 / 手环联网桥接 | 手环当前未连接 | 去「手环」页连接 |
| 内置手环应用 | 安装目录缺少 `band-app.rpk` | 重新安装 Pulse |
| AI 额度数据 | 暂时没有额度数据 | 确认对应 Agent 已登录并至少用过一次；刚启动时等一会儿 |

## 四、手环上的 Pulse 应用打开了，但数据不动

依次检查：

1. 「手环」页顶部是不是显示**已连接**？
2. 手环上的 Pulse 应用保持在前台、屏幕亮着吗？
3. Claude Code 的 hook 装了吗？「设置」→「检测 Agent 接入」看 Claude Code 一行。
4. 装了 hook 之后**重开过 Claude Code 会话**吗？hook 只在新会话生效。

## 五、Agent 状态相关

### 装了 hook，但状态不动或显示未安装

- 装完必须**重开一个 Claude Code 会话**。
- hook 的事件清单扩充过（补了 `UserPromptSubmit`）。旧版本装的 hook 缺这个事件，会如实报「未安装」。**重新点一次「修复」即可**：安装逻辑是先摘旧条目再全量重写，不会堆积重复项。
- 检查 `~/.claude/settings.json` 里有没有含 `pulse-hook.cmd` 的条目。
- 如果你的 `settings.json` 被改坏了，安装前的备份在同目录的 `settings.json.pulse-backup`。

### 会话状态多久才更新？哪些是设计、哪些是故障

三个 Agent 的状态来源完全不同，延迟也不同。**下表里的延迟是设计使然，不是故障**：

| Agent | 检测机制 | 开始延迟 | 说明 |
|---|---|---|---|
| Claude Code | hook 事件（`SessionStart` / `UserPromptSubmit` / `PreToolUse` / `PostToolUse` / `Stop`） | 即时 | **必须装 hook**。没装时退化为轮询转录文件，而转录在思考期间不落盘，「思考中」完全检测不到 |
| Codex | 监听 `~/.codex/sessions` 下的会话文件 | 取决于 Codex 何时写文件 | 无 hook 机制，改不了 |
| Antigravity | 轮询本地 language_server | **约 5 秒** | 是对请求频率的权衡值 |

Antigravity 的**结束**判定还有一层自适应宽限期（4–40 秒），用来防止把任务中途的停顿误判成「已完成」。所以一个有长等待历史的会话，结束后要等更久才显示已完成——**误报完成比慢更糟**，这是有意的。

## 六、安装快应用或表盘失败

- 手环必须**先连上**才能安装。确认「手环」页显示已连接后再操作。
- 快应用只支持 `.rpk`，表盘只支持 `.bin`。
- 提示「已存在于手环，无需重复安装」不是错误，表盘已经在列表里了。
- 内置表盘是设备自带的，不允许删除。

> ⚠️ 快应用和表盘功能只在作者本人的小米手环 10 上验证过。如果连上了但安装仍然失败，请附上诊断报告。

## 七、提 issue 之前

请附上：

- Windows 版本、Pulse 版本（「设置」→「版本与环境」）和手环型号
- 「运行诊断」→「一键完整诊断」→ **「复制报告」** 得到的脱敏文本

诊断报告已经自动脱敏，不含密钥和完整蓝牙地址。**如果你另外贴了其他日志或截图，先检查里面有没有密钥**——那串东西等于你手环的钥匙。
