# Pulse

把 Claude Code 的实时工作状态推到你的**小米手环 10** 上。

抬手就能看见 AI 在跑哪个工具、跑了多久、额度还剩多少——不用切回电脑，不用盯着屏幕等。

## 先看你能不能用

这不是「下载双击就能用」的软件。小米手环 10 本身无法联网，需要借助 OronBox 联网才能实现实时监控，因此需要下面**全部**条件：

| 需要 | 说明 |
|---|---|
| 小米手环 10 | 只在 Band 10 上做过开发和验证 |
| 一台安卓手机 | 用来绑定手环并导出日志取密钥。**iOS 未验证** |
| Windows 10 / 11 电脑 | Pulse 和 OronBox 必须装在同一台机器上 |
| [OronBox](https://github.com/OrPudding/OronBox) | 第三方开源软件，负责和手环通信。**需要你自己安装** |
| 一点耐心 | 最难的一步是从手机日志里取出手环的 authkey |

> ⚠️ **重要：连接 Pulse 或 OronBox 会断开手环与小米运动健康的蓝牙连接。** 小米手环 10 同一时间只能连接一个蓝牙设备。退出 Pulse 后，手环不会自动切回手机；需要在手环上选择「连接新手机」，再重新连接小米运动健康。目前没有更便捷的切换方式。
>
> 连接 OronBox 后，手环的时间也可能显示异常。目前只确认了这个现象，原因疑似在 OronBox 一侧，Pulse 暂时无法修复或规避。

**如果你没有小米手环 10**，Pulse 仍然可以当一个桌面悬浮岛用（见下面「悬浮岛」一节），但那不是这个项目的重点。

## 快速上手

1. 从 [Releases](../../releases) 下载 `Pulse-Setup-1.1.0.exe` 并安装。
2. 打开 Pulse → 「设置与维护」→ 点 **「安装 Hook」**，重开一个 Claude Code 会话。此时悬浮岛已经能动了。
3. 手环部分照着 **[docs/手环配对指南.md](docs/手环配对指南.md)** 一步步做。

> Pulse 启动时不会打开 OronBox，也不会连接手环。需要使用手环时，请在「设备管理」中手动点击连接；从托盘退出 Pulse 会同时停止 OronBox，避免继续占用蓝牙。

卡住了先看 **[docs/故障排查.md](docs/故障排查.md)**——里面记了几条试错换来的结论，能省你几个小时。

## 它做了什么

- **实时状态**：Claude Code 的会话开始/结束、每一次工具调用，通过 hook 毫秒级推到 Pulse。
- **推到手环**：Pulse 经由 OronBox 把状态送到手环上的快应用，抬手就能看。
- **额度**：Claude / Codex / Antigravity 的用量窗口，手环上一屏看完。
- **一键接入**：「安装 Hook」按钮自动写好 `~/.claude/settings.json`，用 Pulse 自带的运行时执行转发脚本，**你不需要另外安装 Node.js**。
- **内置手环应用**：手环端的 `.rpk` 随安装包一起发布，连上手环后一个按钮推送过去，不用自己找文件。
- **可复制诊断**：一键诊断和异常日志都能脱敏后复制，方便提交 GitHub Issue。
- **三页 PC 端**：「设备管理」负责日常连接，「运行诊断」负责排错，「设置与维护」集中首次配对与开发工具。

## 悬浮岛（附加）

Pulse 同时提供一个桌面悬浮岛：半透明胶囊，显示当前活跃的 Agent、正在执行的工具和计时器，可拖拽、边缘磁吸、双击展开。不需要手环也能用。

## 隐私与网络

- Pulse 的本地状态服务只监听 `127.0.0.1:8765`，**不对局域网开放**。同一个 WiFi 下的其他人看不到你的会话数据。
- 「从手机日志里取 authkey」功能只在本机解析，临时解压的日志副本用完立即删除，**不写入任何配置文件，也不联网上传**。
- authkey 只在主进程里出现，不会下发到界面进程，也不会写进日志。

---

## 已知限制

- **手环端的 `.rpk` 只在作者本人的小米手环 10 上验证过。** 如果推送失败或装上打不开，请提交 issue 并附上 OronBox 的日志。
- 取密钥的流程基于安卓版小米运动健康 / 小米健康研究。**iOS 的日志导出路径未验证。**
- 每次在小米运动健康里重新绑定手环，authkey 都会更换，需要重新取一次。

## 从源码构建

```bash
npm install
npm run dist     # 产物在 release/
```

手环端（可选，需要 [aiot-toolkit](https://www.npmjs.com/package/aiot-toolkit)）：

```bash
cd band-app && npm install && npm run build
```
